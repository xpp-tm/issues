# XPP issues

This is the public issue tracker for **XPP**, a native Windows companion for Trackmania.

- **Found a bug?** [Open a bug report](https://github.com/xpp-tm/issues/issues/new?template=bug_report.yml).
- **Have an idea?** [Suggest a feature](https://github.com/xpp-tm/issues/issues/new?template=feature_request.yml).
- **Security problem?** Please don't post it publicly. See [SECURITY.md](SECURITY.md).

Before you open an issue, please search the existing ones to see if someone has already reported it.
